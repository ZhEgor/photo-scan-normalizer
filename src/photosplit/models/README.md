# Bundled model

`face_detection_yunet_2023mar.onnx` is the YuNet face detector from
[OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet),
used to work out which way up a scanned photo belongs.

- Source: `opencv_zoo/models/face_detection_yunet/face_detection_yunet_2023mar.onnx`
- License: MIT (see the model's `LICENSE` in OpenCV Zoo)
- Size: ~230 KB, no download at runtime
